            ClassLab 使用指引
            
        
            
      
            
      
            
        
            1. 从 Notebook 发布互动练习
            
        
              
          
            1. 打开 CS2310_Score_Analysis.ipynb，在 GitHub 点击 Download raw file 下载示例教材（74 Cells / 5 题）。
              2. 
          
            2. 创建课堂后默认进入「课前备课」，也可先在创建课堂页面点击「课前备课」准备；发布前须创建课堂。
              3. 
          
            3. 在「导入 Notebook」上传文件，系统识别五道互动练习。使用「搜索单元」和「筛选类型」寻找 Cell。
              4. 
          
            4. 选择 Cell 可查看源码预览。普通 C++ Cell 需要点击「用此 Cell 作为起始代码」；标记的互动练习会尝试自动载入，或点击「载入互动练习」，如有未保存的修改会提示确认。
              5. 
          
            5. 核对标题、任务说明、起始代码，并展开「测试用例与易错点」检查预填内容；可按教学需要修改。只有点击「发布为当前任务」才会把任务发送给学生。预览和载入均不等于发布。
              6. 
        
            
      
            
      
            
        
            2. 邀请学生并查看课堂反馈
            
        
            在「邀请学生加入」分享二维码或加入链接。学生在浏览器编辑代码、运行（取决于模式及执行器状态）及提交。教师在「课堂进度」查看提交人数、评测结果、共同失败的测试、常见编译诊断、全班共同修改及备课预期与提交反馈。这些统计是教学复核线索，并非 AI 对学生思考过程的判断。
            
      
            
      
            
        
            3. 连续发布及回顾历史任务
            
        
            无需重新上传 Notebook：选择下一道互动练习，确认新题的标题、代码、用例和易错点已正确载入，再点击「发布为当前任务」。学生端在跟随最新任务时自动收到新题。
            
        
            旧任务及提交不会被删除。使用「查看已发布任务」切换历史任务，查看该题的提交、评测和课堂分析；此操作不会改变学生当前任务。选择「最新发布」返回当前进度。关闭或重新加载页面后需要重新导入 Notebook。
            
      
            
      
            
        
            4. 准备自己的 Notebook
            
        
            在合法 C++ Code Cell 的源码开头（如使用 %%cpp，放在该指令之后）添加标记：
            
        
            // @classlab exercise: Fix the loop boundary
            
        
            普通代码可预览并手动载入；带标记的互动练习可自动识别。测试用例、说明和易错点可通过可选 Metadata 预填，或在编辑器中添加。详见 Notebook 标记与 Metadata 说明。
            
      
            
      
            
        
            5. 真实编译与评测
            
        
            此实验分支的 Judge 通过本地真实 GCC 编译审查过的源码。Run 支持同一个进程多次输入、EOF 和停止；Submit 仍使用完整测试输入。未经审查的源码只收件、不评测。未连接 Judge 时仍可收集代码和查看课堂记录，但不会产生编译或评测结果。
