            ClassLab user guide
            
        
            
      
            
      
            
        
            1. Publish an interactive exercise from a notebook
            
        
              
          
            1. Open CS2310_Score_Analysis.ipynb and select Download raw file on GitHub to get the sample notebook (74 cells / 5 exercises).
              2. 
          
            2. Creating a classroom opens Lesson preparation. You can also select Lesson preparation on the setup page and create the classroom when you are ready to publish.
              3. 
          
            3. Upload the file under Import notebook. ClassLab detects five interactive exercises. Use Search cells and Filter by type to find a cell.
              4. 
          
            4. Select a cell to preview its source. For an ordinary C++ cell, select Use this cell as starter code. Marked exercises load automatically or can be loaded with Load interactive exercise. You will be asked to confirm before replacing unsaved edits.
              5. 
          
            5. Review the title, description, and starter code. Expand Test cases and pitfalls to check or edit the prefilled entries. Select Publish as current task to send the exercise to students.
              6. 
        
            
      
            
      
            
        
            2. Invite students and review classroom feedback
            
        
            Share the QR code or link under Invite students. Students can edit and submit in their browsers and run code when the mode and runner allow it. Classroom progress shows submission counts, grading results, common test failures, compiler diagnostics, shared edits, and expected pitfalls. Use these observations to discuss students' work. ClassLab does not infer their reasoning with AI.
            
      
            
      
            
        
            3. Publish the next exercise and review earlier tasks
            
        
            Select the next interactive exercise in the same notebook. Check its title, code, cases, and pitfalls, then select Publish as current task. Students following the latest task receive it automatically.
            
        
            Earlier tasks and submissions remain available. Use View published tasks to review submissions, grading, and analysis for an earlier task. Students keep their current task. Choose Latest task to return to live progress. Import the notebook again after closing or reloading the page.
            
      
            
      
            
        
            4. Prepare your own notebook
            
        
            Place this marker at the beginning of a valid C++ code cell, after the %%cpp directive if present:
            
        
            // @classlab exercise: Fix the loop boundary
            
        
            You can preview and manually load ordinary code. ClassLab detects marked interactive exercises automatically. Add cases, descriptions, and pitfalls through optional metadata or in the editor. See Notebook markers and metadata.
            
      
            
      
            
        
            5. Standard mode and demo mode
            
        
            Live C++ runs and grading in standard mode require a verified isolated judge. Demo mode replays matching fixtures without compiling arbitrary C++. Classroom joins, submission records, and classroom analysis use live activity in both modes.
